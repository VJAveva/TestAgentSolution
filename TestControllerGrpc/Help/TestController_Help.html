TestController — Help & Feature Guide

Version 1.0 — WatchList Editor, Execution Engine & Agent Management

Getting Started

TestController manages WatchLists — XML-based configurations that define:

  • WatchItems — monitored folder paths with file filters
  • Events — trigger types (Renamed, Created, Changed)
  • Actions — commands executed when events fire (local, remote, email)
  • Templates — reusable action pipelines referenced via <Ref>

Ribbon Tabs

HOME — File & CRUD

  • Open / Save / Save As — Load and save WatchList XML files
  • Import / Export — Merge WatchItems from other files or export selections
  • Edit XML — Open the full WatchList in the XML editor
  • WatchList group — Add WatchItem, Event, Group, Action, Ref, Init nodes
  • Templates group — Add/edit/delete templates (visible when Templates tab is active)

EXECUTION — Run & Control

  • Execute All — Run all enabled WatchItems
  • Trigger Item / Event — Run selected WatchItem or Event
  • Exec Group / Action — Run selected ActionGroup or single Action
  • Reset Status — Clear all execution status indicators
  • Cancel — Cancel running execution (appears only during execution)
  • Retry Failed — Re-execute only failed actions from the last session

TOOLS — Appearance & Help

  • Theme — Switch between Dark, Light, and other themes
  • Help — Opens this help file

WatchList Tree

The left panel shows the WatchList hierarchy. Right-click any node for context-sensitive actions.

  • Drag & drop — Reorder Action/Group/Ref nodes within the same Event
  • Search — Use the search box above the tree to filter nodes by name or tag
  • Status icons — Green dot = Success, Red = Failed, Blue = Running

Agent Management

The right panel manages remote agents connected via gRPC.

  • Register + Test — Add an agent with name and http://host:port address
  • Test / Test All — Verify agent connectivity and retrieve metrics
  • Diagnose — Run full connectivity diagnostic (DNS, TCP, gRPC, Snapshot)
  • Health Check — Automatic background polling every 30 seconds
  • Self-registration — Agents can register themselves via the gRPC server

Initialize (Parameter Files)

Initialize nodes load key-value pairs from .txt files. Tokens like [ServerName] in Action commands are resolved at execution time.

  • Select an Initialize node to browse, edit, and save parameter files inline
  • Tokens are shown resolved in the tree display text

Execution Log

  • Filter — By Tag, Agent, Level (Info/Success/Warning/Error), or free-text search
  • Auto-scroll — Enable/disable automatic scroll to latest entry
  • Pause — Temporarily stop live updates
  • Export — Save log to a text file
  • Copy Failed — Copy only error entries to clipboard
