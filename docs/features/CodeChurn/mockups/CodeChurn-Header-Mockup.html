Read this before you build

The Before view shows one aabootstrap row consuming the whole viewport. That is not the header's fault — it is 25 test-case chips rendering inline in the Manual column. Switch to After and the same row is 3 chips plus a +22 more popover. Header work alone would have moved the problem, not fixed it.

At 1024px watch the stat strip collapse into a single button and four filters move into ⋯ More with a badge showing how many of the hidden ones are active. Nothing wraps at any width. That is the acceptance bar for Checkpoint 3.

Both zero-tone stats stay on screen at every width. 0 Unresolved in grey is the whole point — a metric that disappears at zero cannot be noticed when it turns into one.
