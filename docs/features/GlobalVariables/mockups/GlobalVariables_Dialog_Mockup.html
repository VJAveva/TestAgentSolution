How this works

  1. Pick the build below (Drop Location). The Build Number and Release fill in automatically.
  2. Apply Build to All Pipelines saves it to GlobalVariables.json — one file, nothing else is rewritten.
  3. Every pipeline of that same release uses this build. Other releases are not touched.

A trigger file’s build still overrides this for a one-off run. Safe on a WatchList that spans releases: each pipeline uses this build only if its release matches, so the others are untouched.
