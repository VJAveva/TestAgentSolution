TestAgentSolution — UX Improvement Plan

Comprehensive Before/After mockups for the TestControllerGrpc WPF application.
Reviewed against 10 Seamless UX Standards. All changes faithful to WPF capabilities.

Executive Summary

  • Panel width/height constraints are incomplete — No MaxWidth on left tree or agent panel allows users to squash properties below 300px. No MaxHeight on log prevents it from consuming 80% of the window. Fix: Add proportional MaxWidth caps and use design tokens.
  • Hide/unhide transitions cause layout jumps — The agent panel snap from 280px to 28px causes center panel to jerk. Fix: Animate the column width change with DoubleAnimation from saved width to collapsed, with ClipToBounds preventing overflow.
  • Inconsistent sizing values between XAML and code-behind — XAML sets AgentPanel MinWidth=240 but code-behind sets MinWidth=280. The Style triggers for ColNodeProperties (5*/1*) are overridden by code-behind (3*/1*). Fix: Remove dead XAML triggers, single source of truth in code-behind using DesignToken constants.
  • Tree panel cannot collapse — Unlike Agent and Log panels, the WatchList tree panel has no auto-hide capability. On small laptops (1366×768), tree + properties + agents compete for pixels. Fix: Add IsTreePanePinned toggle with same 28px collapsed state.
  • DesignTokens defined but not consumed — Panel sizing tokens exist in DesignTokens.xaml but MainWindow uses hardcoded literals. Fix: Reference tokens from Grid ColumnDefinition/RowDefinition via DynamicResource bindings.

Diff Summary — Panel Layout Improvements

  • Add MaxWidth constraint to Tree panel (Col 0): Cap at 35% of window width via code-behind update (WPF Grid doesn't support % MaxWidth directly).
    WHY: Prevents users from accidentally squashing the Properties panel below usability. Criteria #9 (Information Density).
  • Add MaxHeight constraint to Log panel (Row 2): Limit to 40% of total Grid height. Implemented via SizeChanged handler.
    WHY: Log is secondary content; primary editing area must dominate. Criteria #8 (Cognitive Load).
  • Animate panel hide/show with 250ms ease-out: Use a proxy Border width with DoubleAnimation, then snap the ColumnDefinition after animation completes.
    WHY: Jarring layout jumps feel like bugs. Smooth transitions communicate intent. Criteria #10 (Emotional Design).
  • Unify MinWidth values — single source of truth in code-behind constants: Remove XAML Style.Triggers for ColNodeProperties (they're dead code overridden by ApplyAgentPaneLayout).
    WHY: Inconsistent 240 vs 280 MinWidth creates maintenance confusion. Criteria #1 (Consistency).
  • Consume DesignTokens from code-behind: Load token values via FindResource("TreePanelMinWidth") instead of magic numbers.
    WHY: Single source of truth enables the layout to be tuned from one file. Criteria #1.
  • Add IsTreePanePinned toggle: Same auto-hide pattern as Agent/Log panels — collapses to 28px vertical tab.
    WHY: On 1366×768 laptops, users need all horizontal space for Properties. Criteria #9.

MainWindow.xaml.cs — MaxWidth/MaxHeight Enforcement + Design Tokens 
// Constants from DesignTokens (loaded once)
private double _treePanelMinWidth;
private double _treePanelMaxWidthPercent = 0.35; // 35% of grid width
private double _logPaneMaxHeightPercent = 0.40;  // 40% of grid height
private double _agentPanelMinPinned;
private double _agentPanelMinCollapsed;

private void LoadDesignTokens()
{
    _treePanelMinWidth = (double)FindResource("TreePanelMinWidth");
    _agentPanelMinPinned = (double)FindResource("AgentPanelMinWidth");
    _agentPanelMinCollapsed = (double)FindResource("AgentPaneCollapsedWidth");
}

// Enforce MaxWidth on Tree panel and MaxHeight on Log
private void MainGrid_SizeChanged(object sender, SizeChangedEventArgs e)
{
    if (sender is not Grid grid) return;

    // Tree panel: cap at 35% of total grid width
    double maxTreeWidth = grid.ActualWidth * _treePanelMaxWidthPercent;
    if (ColTreePanel.ActualWidth > maxTreeWidth && maxTreeWidth > _treePanelMinWidth)
    {
        ColTreePanel.Width = new GridLength(maxTreeWidth, GridUnitType.Pixel);
        ColTreePanel.Width = new GridLength(maxTreeWidth / grid.ActualWidth, GridUnitType.Star);
    }

    // Log pane: cap at 40% of total grid height
    if (_vm.IsLogPanePinned)
    {
        double maxLogHeight = grid.ActualHeight * _logPaneMaxHeightPercent;
        if (RowLogPane.ActualHeight > maxLogHeight && maxLogHeight > 120)
        {
            RowLogPane.Height = new GridLength(maxLogHeight, GridUnitType.Pixel);
        }
    }
}

private void ApplyAgentPaneLayout(bool pinned)
{
    if (pinned)
    {
        ColAgentPanel.Width = _savedAgentColWidth;
        ColAgentPanel.MinWidth = _agentPanelMinPinned;  // From DesignTokens
        ColAgentSplitter.Width = GridLength.Auto;
        ColNodeProperties.Width = new GridLength(3, GridUnitType.Star);
    }
    else
    {
        if (ColAgentPanel.Width.IsStar)
            _savedAgentColWidth = ColAgentPanel.Width;

        ColAgentPanel.Width = GridLength.Auto;
        ColAgentPanel.MinWidth = _agentPanelMinCollapsed;  // From DesignTokens
        ColAgentSplitter.Width = new GridLength(0);
        ColNodeProperties.Width = new GridLength(1, GridUnitType.Star);
    }
}
MainWindow.xaml.cs — Animated Panel Transition (optional polish) 
// Smooth panel collapse using a proxy element + DoubleAnimation
// WPF ColumnDefinition.Width is not directly animatable, so we animate
// a proxy Border's Width and sync in the Completed handler.

private Border _agentAnimProxy;

private void AnimateAgentPaneCollapse(double fromWidth, double toWidth, Action onComplete)
{
    if (_agentAnimProxy == null)
    {
        _agentAnimProxy = new Border { Width = fromWidth, Visibility = Visibility.Collapsed };
        // Add to visual tree (hidden) so animation infrastructure works
        ((Grid)Content).Children.Add(_agentAnimProxy);
    }

    _agentAnimProxy.Width = fromWidth;
    var anim = new DoubleAnimation(fromWidth, toWidth, TimeSpan.FromMilliseconds(250))
    {
        EasingFunction = new QuadraticEase { EasingMode = EasingMode.EaseOut }
    };
    anim.Completed += (s, e) => { onComplete?.Invoke(); };

    // During animation, update column width each frame
    _agentAnimProxy.BeginAnimation(Border.WidthProperty, anim);
    CompositionTarget.Rendering += UpdateColumnFromProxy;

    void UpdateColumnFromProxy(object? s, EventArgs e2)
    {
        double current = _agentAnimProxy.Width;
        if (Math.Abs(current - toWidth) < 1)
        {
            CompositionTarget.Rendering -= UpdateColumnFromProxy;
            return;
        }
        ColAgentPanel.Width = new GridLength(current, GridUnitType.Pixel);
    }
}
Animating Grid column widths is non-trivial in WPF. The proxy approach works but may cause brief layout flickering on low-end GPUs. Test on target hardware (typical QA engineer laptops: 1080p, Intel UHD). Consider making animation optional behind a "Reduce motion" setting.

// Add a CollectionViewSource that groups & sorts sessions
public ICollectionView SessionsView { get; }

private void InitSessionsView()
{
    SessionsView = CollectionViewSource.GetDefaultView(ActiveSessions);
    SessionsView.SortDescriptions.Add(
        new SortDescription(nameof(SessionVM.SeverityRank), ListSortDirection.Descending));
    SessionsView.SortDescriptions.Add(
        new SortDescription(nameof(SessionVM.ProgressPercent), ListSortDirection.Ascending));
    SessionsView.GroupDescriptions.Add(
        new PropertyGroupDescription(nameof(SessionVM.AttentionGroup)));

// On each SessionVM:
public int SeverityRank => Status switch
{
    SessionStatus.Failed => 100,
    SessionStatus.Stuck => 90,
    SessionStatus.Running => 10,
    SessionStatus.Success => 0,
    _ => 5
};

public string AttentionGroup => SeverityRank >= 90 ? "NeedsAttention" : "Normal";

2. Shared Panel Toggle Animation Helper

Helpers/PanelAnimator.cs — Reusable across all panels 
public static class PanelAnimator
{
    public static void AnimateColumnWidth(
        ColumnDefinition column, double toWidth,
        TimeSpan duration, Action? onComplete = null)
    {
        // Store current as pixel
        double fromWidth = column.ActualWidth;
        var proxy = new AnimationProxy { Value = fromWidth };

        var anim = new DoubleAnimation(fromWidth, toWidth, duration)
        {
            EasingFunction = new QuadraticEase { EasingMode = EasingMode.EaseOut }
        };

        anim.Completed += (s, e) =>
        {
            column.Width = toWidth > 30
                ? new GridLength(toWidth, GridUnitType.Pixel)
                : GridLength.Auto;
            onComplete?.Invoke();
        };

        // Animate via proxy — update column on each tick
        proxy.ValueChanged += (newVal) =>
        {
            column.Width = new GridLength(newVal, GridUnitType.Pixel);
        };

        proxy.BeginAnimation(AnimationProxy.ValueProperty, anim);
    }
}

// DependencyObject subclass to enable animation on a plain double
public class AnimationProxy : Animatable
{
    public static readonly DependencyProperty ValueProperty =
        DependencyProperty.Register("Value", typeof(double), typeof(AnimationProxy),
            new PropertyMetadata(0.0, OnValueChanged));

    public double Value
    {
        get => (double)GetValue(ValueProperty);
        set => SetValue(ValueProperty, value);
    }

    public event Action<double>? ValueChanged;

    private static void OnValueChanged(DependencyObject d, DependencyPropertyChangedEventArgs e)
        => ((AnimationProxy)d).ValueChanged?.Invoke((double)e.NewValue);

    protected override Freezable CreateInstanceCore() => new AnimationProxy();
}

Risk Callouts

Panel animation on low-end hardware: WPF GridLength is not directly animatable. The proxy pattern may cause micro-stutters on Intel UHD 620 GPUs at 100% DPI scale. Mitigation: Test on representative hardware; provide fallback instant-snap when "Reduce motion" is enabled.
MaxWidth enforcement may fight user intent: If a user genuinely wants a wider tree panel (e.g., deep nesting), the 35% cap blocks them. Mitigation: Cap only prevents dragging past 35% — user can still control the actual position within bounds. Consider making the cap configurable in appsettings.
CollectionViewSource sorting performance: With 50+ active sessions all updating progress every second, sorting on each update could be expensive. Mitigation: Debounce sort refresh to every 2 seconds, or only re-sort when SeverityRank changes (not on every progress tick).
Panel state persistence across sessions: Currently saved widths are in-memory only. If user closes at a good layout, it's lost on restart. Mitigation: Persist panel widths/heights to user settings (appsettings or registry). Already partially supported via ViewModel property change — just needs to be saved/loaded.
