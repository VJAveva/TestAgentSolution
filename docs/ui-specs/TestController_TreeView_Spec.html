Interaction notes

  • Hover — row background changes to --bg-row-hover. Cursor: hand on chevron, default elsewhere.
  • Select — single click selects the row. Background becomes --bg-row-selected. Only one node selected at a time (single-select tree).
  • Expand/collapse — click chevron OR double-click row. Leaves (actions) have no chevron and don't expand.
  • File path pills — show only the filename. Full path appears on hover via tooltip. Click-to-copy is a nice-to-have.
  • Active-run highlight — when a TestItem is Running, its rail (the vertical guide line under it) tints blue (--rail-active) so the eye can follow execution down the tree.
  • Right-click — context menu (out of scope here, but reserve space for it): Run from here, Skip, Edit, Disable, Duplicate.
  • Keyboard — ↑/↓ moves selection, ←/→ collapses/expands, Enter opens edit dialog, Space toggles enabled.

WPF translation hints (for the Copilot)

  • Use TreeView with HierarchicalDataTemplate per node type. Bind to a flat ObservableCollection<ITreeNode> where each node exposes its children.
  • Each HierarchicalDataTemplate should match a DataType (TestItem, EventTrigger, ActionGroup, RunAction, RemoteCommandAction, SendEmailAction, InitializeAction, ReferenceAction).
  • Declare every color in App.xaml as SolidColorBrush resources keyed by the CSS variable name (e.g. BgPanelBrush, CRunBrush). Reference them with DynamicResource so theme switching is possible later.
  • Status dot = a small Ellipse with a DataTrigger swapping the Fill based on the Status enum. The "running" pulse animation = a DoubleAnimation on Opacity, AutoReverse, RepeatBehavior=Forever.
  • Pills = a styled Border with a TextBlock. Define one Style with Tag-based triggers (Tag = "SEQ" / "PAR" / "RUN" / ...) to switch the background and foreground.
  • File pill = Border + TextBlock with TextTrimming="CharacterEllipsis", MaxWidth="200", and ToolTip="{Binding FullPath}".
  • The vertical "rail" can be drawn either by setting a left BorderThickness on the items container, or by a Decorator in the ItemContainerStyle. The active variant is a DataTrigger on IsAncestorOfRunningNode (computed in the view model).
  • Icons: install Material.Icons.WPF or FontAwesome.Sharp. Map: Run→Terminal, RemoteCommand→Server, SendEmail→EmailOutline, Initialize→CogOutline, Reference→ArrowURightTop, EventTrigger→LightningBolt, ActionGroup→FormatListBulletedType, TestItem→TestTube.
  • Do NOT show full file paths inline. Always extract Path.GetFileName(...) for display and bind the full string to ToolTip.
